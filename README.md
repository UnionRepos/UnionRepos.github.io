# UnionRepos

Official website for the [UnionRepos](https://github.com/UnionRepos) organization.

Built with React, TypeScript, Vite, and Tailwind CSS. Pushes to `main` deploy to [unionrepos.github.io](https://unionrepos.github.io/).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
